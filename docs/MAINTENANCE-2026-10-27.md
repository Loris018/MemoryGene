## 修复

1. **会话召回**：适配器 topics 限制为长期主题及解析到的当前会话主题，无会话 ID 时仅返回长期主题。过滤发生在读取被排除会话的事件内容前。核心的全量管理索引保留兼容性。这是逻辑隔离，不是鉴权；任意传入别人的身份或直接访问 SQLite 仍不受权限控制。
2. **验收可信度**：check 只接受布尔判定，所有值/列表/计数改为显式比较。遗忘按目标路由和真实事件 ID 检查，验证同值的其它主题不被删除；BLOB SQL 匹配显式转文本。验收使用固定的虚构时钟，避免到期案例随真实日期失效；同时修复了 forget 接收到测试时钟时报 TypeError 的问题，遗忘仍删除该主题全部记录（含已到期记录）。Harness 汇总纳入每个子检查，要求 session ID、真实且完成的 Skill/适配器工具事件，模型自述不算工具证据。
3. **安装恢复**：权限 0600 的清单保存替换前字节和权限；重复安装沿用第一次备份；卸载仅处理清单中两个文件，保留非托管文件和数据库。发现后续用户编辑时拒绝操作；常规 I/O 失败会尝试恢复操作前状态，不承诺断电事务恢复。旧清单无备份时拒绝破坏性卸载。
4. **现有接入**：更新项目级和用户级 Skill 的读取约束，配置的数据库、身份、执行器路径不变。全局 AGENTS.md 原文未改，自动提示约定保持启用。

旧安装升级的恢复基线是**升级前的安装状态**，不是最早未安装状态。旧安装器没有留下的备份无法重建；本机卸载此次升级会恢复旧 Skill/配置。关闭自动提示仍使用全局指令安装器的 `--uninstall`。
