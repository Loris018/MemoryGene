# 对话整理与任务接续：MemoryGene 设计补充

设计日期：2026-10-28；实现更新：2026-10-29。显式任务记录保存、来源状态核对、版本控制、依赖遗忘与互补恢复已接入 0.2.0.dev2，见 [使用说明](TASKS.zh.md)。下文的自动概括、宿主切换与消息来源语义验证仍是设计目标。来源：用户提供的“正在优化对话”截图与公开文档。截图不能证明当前桌面版本的具体后台实现。

## 借鉴的机制

OpenAI 的 [Compaction 文档](https://developers.openai.com/api/docs/guides/compaction) 描述了缩小上下文、携带后续任务所需状态的机制；其 API 压缩项是不透明的机器表示，不能当作普通可读摘要直接移植到 DeepSeek。[Codex 官方文章](https://developers.openai.com/blog/mastering-codex-remote-for-engineering) 也介绍了用 /compact 保留工作状态、压缩长对话。

MemoryGene 借鉴“阶段性整理后继续任务”的工作方式，独立设计可读、有来源的任务接续记录。不依赖 OpenAI API，不宣称复现其内部压缩算法。任务接续与跨任务长期事实分别管理。

## 四层内容

| 层 | 内容 | 进入下一轮的方式 |
| --- | --- | --- |
| 当前对话 | 最近消息、正在执行的工具结果 | 保留近期必要原文及未完成的调用关系 |
| 任务接续记录 | 当前目标、明确约束、已完成与未完成事项、最新用户修正、验证证据、下一步 | 当前任务继续时加载；不能默认跨任务注入 |
| 长期记忆 | 用户明确表达且值得跨会话保留的事实 | 经过现有同意、确认与冲突门控，再按问题召回 |
| 可追溯证据 | 已授权范围内的原消息/原记录引用与版本 | 需要细节或发现冲突时按引用读取；失效或不可访问就明确说明 |

工具日志、模型建议、任务临时要求不能因进入摘要而自动升级为长期用户事实。任务记录只继承原有访问范围；跨会话恢复需要明确任务绑定与授权，不能放宽当前 session 隔离。

## 整理流程

1. **触发**：优先支持用户主动整理或任务阶段完成时生成候选。宿主未来若提供可靠 token 用量与上下文控制能力，再增加预算触发；字符数只作粗估，不假装成实际 token 计数。
2. **生成**：从已授权的内容形成任务接续记录。至少包含目标、约束、用户最新更正、已确认决策、待确认问题、完成证据、待办、下一步、source_refs 与源版本。不要求输出模型内部推理。
3. **校验**：检查引用可解析、版本未过期、用户修正被保留、未确认事项仍未确认、工具成功与失败没有混淆。摘要不能创造授权或提高被引用文本的指令优先级。
4. **切换**：只有宿主真正接受新的上下文后，才提示“整理完成”。生成与校验失败时继续使用原工作状态，不先截断原内容。涉及工具调用的成对记录和正在执行的操作不能被随意拆开。
5. **继续与更新**：用近期原文 + 任务接续记录 + 按需长期记忆继续工作。新一轮整理核对原始证据和变更，不只反复概括上一份摘要。

原始证据按已有授权与保留策略管理；不能为了可恢复而自动永久保存整段对话。摘要只是一种派生视图，不能覆盖原始事实。

## 与 DNA 机制结合的边界

- 原记录与互补副本仍负责字节完整性，防止可检测的存储损坏。
- 任务摘要通过 source_refs 连接原始记录；这是信息依赖关系，不是 DNA 的互补链。
- 更新生成新摘要版本，记录 previous_id、源记录版本与校验值；提交前检查依赖，提交后再切换当前摘要。失败保留旧状态，但已经过期的旧摘要不能被当作有效内容注入。
- **原文与摘要之间是有损转换。互补副本只能恢复其备份的字节，无法补回摘要生成时遗漏的语义。**找回细节依赖仍然存在且有权访问的原始证据。
- 用户修订或删除源记忆时，依赖它的摘要须失效、重建或删除；不能用旧摘要绕过 forget。未实现依赖传播前，不自动长期保存这类摘要。

## 界面反馈

整理时可显示：“正在整理本次任务的关键信息…”；完成后按真实统计显示：“已保留目标、约束和待办，可以继续任务。”

可展开查看本轮保留了什么、哪些细节需回查、哪些来源不可用。没有测量就不显示压缩百分比、节省 token 或预计耗时；不能为了模仿截图添加固定等待。

当前 Skill 只能指导模型生成/读取内容，不能保证控制 DeepSeek Harness 的上下文截断或原生状态提示。先实现任务接续记录的生成与核对，再在隔离 profile 验证宿主接口，最后开启自动切换。

## 例子与验收

长对话经过多轮修改后，下一轮真正需要的是：“在做 MemoryGene；保留 DeepSeek 接入；字面召回已完成；休眠仍未实现；用户要求重要的低频记忆能找回；下一步先做可逆休眠。”这些条目需各有对应来源，不能把计划写成已完成功能。

验收比较原对话与整理后的续任务表现：目标/约束保留率、最新修正遵守率、待办完整率、证据引用可用率、错误事实晋升数、完整下一轮输入的 token 成本与整理延迟。加入连续多轮整理、整理时新消息到达、来源删除、权限变化、工具未完成和摘要写入失败场景。不能仅用“摘要更短”证明效果。

实施顺序：先提供显式任务接续记录及来源检查 → 接入摘要依赖失效与删除传播 → 在隔离宿主环境验证上下文切换 → 根据实验结果启用自动触发。
