# 实验方案与预注册草案

## 已经跑过的实验

实验 A：24 组虚构结构化场景、47 次输入；每组手写当前答案、确认历史和逐步状态。直接覆盖、保留全部记录、相同规则配普通索引、相同规则配互补索引共用输入。前两者是最低能力基线，无筛选/确定性判断，不能代表成熟记忆系统。比较当前值精确匹配、确认历史序列精确匹配、不应激活的候选被激活次数，以及 7 条 uncertain/inferred 输入的误确认为事实次数。

“历史准确率”对重复已确认值也要求序列精确匹配，是本实验严格且狭窄的定义，不等于自然语言历史问答能力。逐步 trace 和所有分母公开。规则与 fixture 同期开发，100% 结果只作回归验收。plain 与 complement 消融用于把规则收益和编码收益分开。

实验 B1：300 个唯一主题，每种索引执行 7 轮完整查询，记录每轮平均延迟的中位数、正确数、路由键字节和数据库实际大小。protection=none，使索引比较不受副本配置混淆。顺序固定、单机运行，未作统计显著性推断。

实验 B2：固定随机种子 20261024，100 份相同的随机字节 payload，长度 80–299 字节；无保护/普通副本/打包互补副本，测试健康、主副本缺失、首字节单比特错误、备份缺失、两者缺失、摘要丢失。普通副本与互补副本均增加恰好一份 payload 长度的冗余，并使用相同 SHA-256；记录恢复率和开销。本实验是内存中字节级损坏，不是 SQLite 文件级灾难恢复，也不是真实 DNA 测序。

## 实验 C：自然语言提取原型（2026-10-24）

在保留原 24 组结构化开发集之外，新增：

- `src/memorygene/extract.py`：零依赖、确定性的中文规则提取原型（仅用于可复现实验；
  生产路径由调用模型抽取，本模块不声称语义理解）。
- `experiments/nl_cases.json`：47 组全新虚构多轮对话 / 79 轮，人工标注每轮
  topic/value/certainty/intent/importance 档位/是否应写入、预期逐轮状态、最终当前值与确认历史；
  覆盖“也喜欢 vs 最喜欢”、明确改变、犹豫、第三人称、否定、提示注入文本、敏感无同意、到期、冲突。
- `experiments/nl_eval.py`：分两层评分——L1 提取（topic/value/certainty/intent/
  importance/source 最小性/写入决策），L2 存储（同一套核心规则分别喂 oracle 标签候选与
  提取器候选），并把失败案例分类为 extraction-only / storage-only / both / neither。
- 公平性：同一提取与规则管线跑 6 组配置（plain/complement × none/copy/complement），
  copy 与 complement 冗余字节完全相同，断言语义结果一致，并报告路由键与文件开销。

实际结果（详见 [NL_RESULTS.md](../experiments/NL_RESULTS.md)）：

| 指标 | 结果 |
| --- | --- |
| L1 写入/弃权决策 | 77/79（97.47%） |
| L1 topic / certainty / source 最小性 | 57/57 / 57/57 / 57/57（100%） |
| L1 value / intent / importance 档位 | 56/57（98.25%） |
| L2 oracle 当前与确认历史 | 47/47、47/47（100%，说明标签与核心规则一致） |
| L2 提取器当前与确认历史 | 44/47（93.62%） |
| 失败分类 | extraction-only 5、storage-only 0、both 0、neither 0 |
| 6 组配置语义一致性 | 完全一致；copy=complement 冗余 27,163 B；complement 路由键 4.0× plain |

**诚实边界**：提取规则与案例由同一作者同期开发，案例只覆盖规则表涉及的虚构句式；
这不是留出集基准，也不是自然语言理解准确率。oracle 100% 只说明人工标签与核心规则一致，
不构成对核心正确性的独立验证。已知失败案例（复合值、否定、第三人称、低重要性线索、
“也”的歧义）全部公开列在 NL_RESULTS.md。

## 仍未完成：独立自然语言基准与宿主行为评估

1. 冻结当前规则，另写至少 30 组从未用于调规则的对话（真实留出集），用**独立模型**固定版本/提示/
   temperature 抽取，保存原始输出与解析失败，不修补标签。
2. 两名标注者独立标注并报告一致率与仲裁；发布仅使用虚构或明确授权且脱敏的数据。
3. 当前/历史问答正确性、uncertainty false-commit、错误更新、遗漏重要一次性信息、用户隔离泄漏；
   按对话组自助重采样估计区间，避免把同组轮次当独立样本。
4. 主动调用（是否该提及旧记忆）的 precision/recall 与无关打扰率：本版精确主题查询不能代替。
5. 真实 GUI 人工验收：4 个 headless 会话已证明跨会话链路，但尚未由用户在桌面对话中逐项点选。

## 机制实验扩展（尚未执行）

随机化 ordinary/complement 执行次序，多个种子、数据规模和 payload 长度，多次重建文件；
同时测试已有热点和冷缓存，隔离编码时间与纯数据库查询时间。记录环境、p50/p95、实际文件大小，
先检查两组输入和冗余预算相同。

增加“普通编码 + 同等规则 + 同等校验 + 同等备份”的完整消融。按字节/块/整页损坏建模，
区分独立损坏和共因损坏。数据库文件整体消失必须计为失败，不能用原始 fixture 偷渡恢复。
研究部分冗余编码前，先给出明确可恢复条件及相同预算的普通纠删码比较。

## 可证伪结论

若 plain 与 complement 在相同规则、相同预算下效果相同，应报告“规则有用，互补表示未显示独立收益”。
若互补索引更慢或更大，公开其成本，不把可逆重编码称为压缩。神经再巩固仅是更新思想的启发，
尚无神经或生物机制实验。

## 实验 D：独立留出自然语言基准（2026-10-29，已执行）

与实验 C 不同：这里用**全新 30 组虚构对话 / 40 轮**（未用于调提示或规则）+ **独立模型**抽取（DSH headless
`deepseek-flash`，固定提示模板，6 个真实会话），再与人工标签 oracle 跑同一套 MemoryGene 策略；标签未展示给模型。

结果（详见 [experiments/heldout-2026-10-29/RESULT.md](../experiments/heldout-2026-10-29/RESULT.md)）：

| 层 | 指标 | 结果 |
| --- | --- | --- |
| L1 | 写入/弃权决策 | 36/40（90.0%，Wilson 76.9%–96.0%） |
| L1 | value / certainty / intent / source / consent | 26/27、26/27、26/27、27/27、27/27 |
| L1 | **topic 精确字符串** | **11/27（40.7%）**，同义/细粒度命名是主要缺口 |
| L1 | importance 档位 | 16/27（59.3%） |
| L2 | oracle 最终 current / 确认历史 | 30/30 / 30/30（只说明标签与策略自洽） |
| L2 | 独立模型最终 current / 确认历史 | **20/30 / 20/30** |
| L2 | 失败分类 | extraction-only 10、storage-only 0、both 0、neither 20 |

结论：本批中**所有 L2 失败都能追溯到抽取**（主要是 topic 命名，另有未来计划误写、也喜欢/更喜欢误判等），
没有观察到存储策略单独算错。但独立模型没有规范 topic 表，40.7% 的 topic 精确率说明真实接入需要
**适配层 topic 归一化**，且改动后必须用新的留出集重测。该结果不用于修改核心/规则/提示，也不与规则提取器
的 57/57 直接比较（任务、分母、是否留出均不同）。
